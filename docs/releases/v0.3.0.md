# Supabase Local v0.3.0

The Windows installer and desktop launcher now use Rust and GPUI Kit, with the original Supabase branding.

- Redesigned desktop dashboard with six-service status and an activity log.
- Windows notification-area icon with Show, Open Studio, Restart and Exit.
- Confirmation dialogs before restarting or exiting, including window close.
- Graceful service restart and shutdown, preserving project data and secrets.
- Live installation logs and detailed Windows integration errors.
- Full bundled Windows x64 installer; no Docker or WSL2 required.

Close the older Supabase Local launcher before running `SupabaseLocal.Setup.exe`. Installation is per Windows account and retains existing project data. The ASP.NET service manager and separate C# uninstaller remain included. This is an unofficial native Windows port; Realtime, Edge Functions and analytics are not included.

Validation: all 11 Rust tests passed; the bundled release passed integrity, repeat-install, tamper-rejection and data-preservation checks, plus two SQL/Auth/REST/Storage integration cycles. The Rust launcher passed native dashboard/tray/dialog rendering and real restart/shutdown tests with preserved secrets and stored files.
