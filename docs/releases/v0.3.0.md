# Supabase Desktop v0.3.0

The Windows installer, desktop launcher and uninstaller use Rust and GPUI Kit, with Supabase Desktop branding and the original Supabase logo.

- Redesigned desktop dashboard with six-service status and an activity log.
- Windows notification-area icon with Show, Open Studio, Restart and Exit.
- Confirmation dialogs before restarting or exiting, including window close.
- Graceful service restart and shutdown, preserving project data and secrets.
- Live installation logs and detailed Windows integration errors.
- Native Rust uninstaller with project data preserved by default, confirmed data deletion, running-app checks and safe removal of NTFS junctions.
- Full bundled Windows x64 installer; no Docker or WSL2 required.

Close the older launcher before running `SupabaseDesktop.Setup.exe`. Installation is per Windows account and retains existing project data. The ASP.NET service manager remains included; the uninstaller is now built in Rust. This is an unofficial native Windows port; Realtime, Edge Functions and analytics are not included.

Validation: all 13 Rust tests passed; the rebuilt installer passed integrity, repeat-install, tamper-rejection and data-preservation checks, plus two SQL/Auth/REST/Storage integration cycles. The packaged Rust launcher passed native dashboard/tray/dialog rendering and real restart/shutdown checks. The packaged Rust uninstaller passed ownership, running-app rejection, junction safety, data preservation, explicit data deletion, copied-worker cleanup and native confirmation-dialog checks.
